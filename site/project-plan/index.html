Project plan¶

Deliverables¶

GIS report¶

A complete report documenting the research question, data, methodology, results, discussion, and conclusions.

GitHub repository¶

The repository will contain:

  • documented data sources;
  • Python analysis;
  • processed spatial data;
  • outputs;
  • project documentation.

Cartographic output¶

Final maps produced using QGIS.

Public article¶

A shorter version of the project presenting the main findings and maps, with links to the full report and repository.

Phase 1 schedule¶

Week Main activity Expected output
1 Data research, acquisition, and prototype Working prototype
2 Data processing and validation National analytical dataset
3 Analysis and cartography Results and maps
4 Report, repository, and publication Phase 1 v1.0

Definition of done¶

Phase 1 is complete when:

  • Data sources are documented.
  • The methodology is documented.
  • All spatial calculations use EPSG:28992.
  • The prototype works.
  • The national dataset has been processed.
  • Data-quality checks have been completed.
  • Metric distributions have been examined.
  • A classification method has been justified.
  • Final maps have been produced.
  • The report is complete.
  • The GitHub repository is reproducible.
  • The public article has been published.
