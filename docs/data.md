# 3. Data

**Table 1.** Data sources used in the analysis.

| Dataset | Source | Purpose |
| --- | --- | --- |
| Railway stations | OSM / NS / ProRail | Analysis units |
| Cycling infrastructure | OpenStreetMap | Cycling metric |
| Roads | OpenStreetMap | Road metric |
| Public-transport stops | GTFS | PT metric |
| Population | CBS 100 m grid | Population metric |
| Waterways | PDOK / Dutch open data | Geographic context |

For every dataset, the project will document:

- Source
- URL
- Access date
- CRS
- Relevant fields/tags
- Processing
- Limitations
